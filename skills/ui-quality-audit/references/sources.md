# Authoritative sources

Use these when citing. Prefer primary docs over blogs.

## Usability & UX

| Source | Stars / standing | Use for |
|--------|------------------|---------|
| [NN/g — 10 Usability Heuristics](https://www.nngroup.com/articles/ten-usability-heuristics/) | Industry standard since 1994 | H1–H10 |
| [Laws of UX](https://lawsofux.com/) | Widely cited design psychology set | Fitts, Hick, Miller, Jakob, Doherty, … |
| Don Norman — *The Design of Everyday Things* | Canonical HCI | Affordances, signifiers, mapping, feedback |
| [Tog’s First Principles](https://asktog.com/atc/principles-of-interaction-design/) | Long-standing HCI checklist | Extra interaction principles |
